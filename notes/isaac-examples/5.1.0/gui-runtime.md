# Qt 與 Isaac Sim 子程序、預覽和視窗輸入

Isaac Sim 5.1.0 工程案例。Qt 啟動獨立 Isaac Sim Python 子程序；先在參數中傳入場景與所需 extension 設定。UI 和模擬各維持事件迴圈。用子程序啟動、Stage 就緒及連線就緒區分不同狀態，逾時要暴露子程序日誌。啟停流程只管理本次會話的子程序，先要求正常停止、等待，再處理未退出的程序。

X11 環境可依子程序樹查找視窗、核對候選視窗屬於目前會話，再 reparent 到 Qt 容器。初始化非同步時以短時間重試，resize 後同步 viewport 尺寸，退出時移除舊視窗關聯。Wayland 或不支援嵌入的環境可用獨立視窗。將場景載入、播放控制與內嵌視窗測試分開。隱藏的 2D 視圖可停止重繪，事件接收和資料處理仍獨立運作。

站點的 3D 預覽可交給另一個輕量子程序，引用模型並用狀態快照更新標記與攝影機。使用局部 BBox 和 `metersPerUnit` 換算實際尺寸，切換資產時重設邊界和相機。測試錯誤路徑、啟動延遲、多進程切換、重複 resize、停止與重啟。
