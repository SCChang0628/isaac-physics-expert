# 卸貨站對位與通過式站點轉送

Isaac Sim 5.1.0 工程案例。卸貨對位是由明確的載具、站點與交易 token 定位的操作。控制端先保留資產，等夾爪脫離且收回後確認請求有效，再以站點世界矩陣和載具根至剛體偏移計算目標。檢查目前位姿、平移與角度誤差、占用和限制，捕捉範圍外直接回報原因。四元數角度差應用絕對內積處理 `q` 與 `-q` 的等價性。合法條件下最多修正一次，在後續數幀分別確認水平、高度、角度和低速穩定窗。逾時不重複瞬移，並以 token 拒收過期結果。

通過式站點的雙端轉送只對明確標記為此模式的站點啟用。依兩端的進出貨方向決定能否轉送，確認目的端可用、載具穩定且未被抓取或保留。搬移成功後以該載具到站記錄鎖定，等它離開或被拾取才重新啟用，避免雙向站點來回搬。對位與回位、通過式轉送應共享互斥的保留狀態。

驗證使用有旋轉的站點、相異根節點與剛體偏移、占用目的端、仍被夾住、超差、取消、重複請求，以及修正後再滑動。斷言最終回報與物理狀態完全對應。
