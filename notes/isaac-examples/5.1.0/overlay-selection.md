# 即時標籤、雙向選取與攝影機跟隨

Isaac Sim 5.1.0 工程案例。快取標籤分類、顏色與 anchor 的局部偏移。對場景結構可證明靜態的工作站，可快取由 USD 計算的世界座標。只要有剛體祖先、時間取樣 xform 或驅動圖，就走 live transform。若另有直接在 Fabric 修改位置的控制器，將其目標明列為動態。參考、父層變換、anchor 與停靠點屬性變動才重建受影響項目。局部 dock 位移先用 anchor 的世界矩陣轉換，再加世界高度偏移。刷新畫面可獨立降頻，資料更新持續進行。

外部介面與 viewport 雙向同步時，把點到的子 mesh 映射至邏輯物件根節點，再發布選取事件。同步回寫要預防事件迴圈，並核對訊息屬於目前載入的場景。攝影機跟隨以物件的即時位置及所選 anchor 為準，保存眼點相對目標的偏移。離開跟隨時，僅在目前選取仍對應原跟隨目標時清除選取和資訊卡。

驗證覆蓋新增、刪除、停用及父子變換更新。操作測試涵蓋 viewport 點選子 mesh、外部介面切換不同物件、取消跟隨，以及暫停／重播後的即時座標。
