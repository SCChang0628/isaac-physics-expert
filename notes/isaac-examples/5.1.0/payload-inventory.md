# 載具初始化、狀態快照與就緒回報

Isaac Sim 5.1.0 工程案例。用場景或設定的宣告式清單描述應出現的載具，包含資產參考、初始位置、角度、是否啟用和目標的 revision。端點發送整份快照時以同目錄暫存檔、flush 後 `os.replace` 原子更新，避免讀者拿到半份 JSON。執行期將參考及覆寫寫入 Session Layer，使用 composed Stage 驗證資產已解析。

就緒快照區分目標 revision、已實現 revision、暫時阻擋及檢查錯誤。上層只有在同一載具及目標 revision 就緒時才繼續。回位命令先解析剛體相對資產根節點的偏移，將目標根 pose 換算成剛體 pose，再處理 PhysX。已吸附、目的區已占用或另一個交易已保留時，延後或拒絕。外觀標記可在狀態變動時才 author，以降低 Session Layer 編輯通知量。

驗證資產找不到、舊回報晚到、命令重複、回報檔損壞、被夾持、占用拒絕及暫停後恢復。每個系統應依負載、尺寸和控制頻率校正位置、角度、速度和逾時門檻。
