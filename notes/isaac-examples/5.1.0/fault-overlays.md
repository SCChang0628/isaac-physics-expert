# 故障快照、世界座標邊界與 Debug Draw

Isaac Sim 5.1.0 工程案例。狀態來源把已生效的故障寫為一份原子快照，讀取端降頻輪詢，依邏輯物件 ID 解析模型。同一機台的子連接埠應映射回同一個機台，以免重複畫框。為移動機械使用車體或對應剛體的局部 BBox，選定應包含的 USD purposes；將八個角以即時世界矩陣變換，畫出十二條唯一邊。可用 `isaacsim.util.debug_draw`，由同一個 runtime 元件統一管理線段批次。

故障可以在暫停時保留，復歸時清除顯示。快照讀取應能處理檔案缺少、JSON 損壞、未知目標及物件移除。局部 BBox 和世界矩陣各有自己的失效條件。若使用全域 `clear_lines()`，應協調各 overlay 的繪製，避免清掉其他元件。

測試有旋轉、比例及局部偏移的模型，核對十二邊、世界中心與即時位置，並覆蓋故障回復和快照損壞。程式可斷言線段和變換；顏色、遮擋及 GPU 畫面需要另做視覺檢查。
